# Проверка простого просмотра изображений

Статус: PARTIAL. Экспериментальная ветка, не включать в production до проверки интерфейса.

Нажатие на изображение кейса или галереи раздела открывает отдельный dialog.
В нём две подписанные кнопки: «Закрыть фото» и «Увеличить / Уменьшить».
Длинное фото прокручивается; увеличение вдвое меняет только изображение.
Нет fullscreen API, переключения кадров свайпом и самописного pinch-zoom.
Используется тот же URL изображения; повышение исходного качества не обещается.

Автоматически проверены: закрытие, восстановление прокрутки/фокуса/жестов,
масштаб, повторное открытие, ошибка загрузки и отсутствие dialog API.
Эти тесты используют модель DOM и не доказывают корректность визуальной раскладки.

Для браузерной проверки: `python scripts/build_viewer_preview.py` генерирует
локальную HTML-страницу с двумя окнами (390 и 800 px) и синтетическим длинным
макетом. Открыть напечатанный путь в обычном браузере. Настоящие клиентские данные
и Telegram API не используются.

BLOCKED в среде текущего аудита: запуск локального Chromium запрещён средой;
облачный браузер не открывает file://. Скриншоты и визуальное прохождение
не получены. Обход ограничений не выполнялся.
