# Просмотр изображений кейса

Изображение открывается по нажатию в отдельном слое внутри текущего окна Mini App.
Размер окна Telegram не меняется. Доступны pinch-zoom (1–4×), двойное нажатие,
перемещение фото пальцем/мышью, кнопка увеличения и явная «Закрыть фото».
Длинные изображения открываются по ширине и прокручиваются внутри просмотрщика.
Escape и Telegram BackButton закрывают фото; позиция кейса и фокус восстанавливаются.
Свайп не переключает фотографии, fullscreen API не вызывается.
Используется прежний URL изображения: увеличение не повышает качество исходника.

Тесты проверяют жесты, ограничения масштаба, переход pinch→pan, отмену указателя,
подавление дублирующего mouse-события после touch, закрытие/возврат, состояние
жестов Telegram и ошибку загрузки. Модель DOM не заменяет реальный мобильный WebView.

По решению владельца проверка выполняется после публикации в рабочем Mini App,
с возможностью отката. Предыдущая версия: 691ebff6f7b226425ac4d3be4975cfe9449560b7.
