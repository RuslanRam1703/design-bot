# Просмотр изображений кейса

Изображение открывается по нажатию в отдельном слое внутри текущего окна Mini App.
Размер окна Telegram не меняется. Доступны pinch-zoom (1–4×), двойное нажатие,
перемещение фото пальцем/мышью, кнопка увеличения и явная «Закрыть фото».
При открытии фото целиком вписывается в область просмотра и центрируется.
После увеличения доступно перемещение. Длинный макет сначала виден целиком.
Escape и Telegram BackButton закрывают фото; позиция кейса и фокус восстанавливаются.
Свайп влево/вправо переключает фотографии только при обычном масштабе.
При увеличении жест перемещает фото. Есть стрелки и счётчик; fullscreen API не вызывается.
В закрытом виде галерея показывает один кадр и миниатюры; после закрытия выбран
последний просмотренный кадр. Галереи разделов сохраняют свою группировку.
Используется прежний URL изображения: увеличение не повышает качество исходника.

Тесты проверяют жесты, ограничения масштаба, переход pinch→pan, отмену указателя,
подавление дублирующего mouse-события после touch, закрытие/возврат, состояние
жестов Telegram и ошибку загрузки. Модель DOM не заменяет реальный мобильный WebView.

По решению владельца проверка выполняется после публикации в рабочем Mini App,
с возможностью отката. Предыдущая версия: 691ebff6f7b226425ac4d3be4975cfe9449560b7.
Откат: revert merge-коммита PR #42 и штатное развёртывание обоих сервисов;

## Демонстрационный кейс

По разрешению владельца добавляется в обычное портфолио один опубликованный кейс
«Тестовая галерея — 3 формата». Это стандартная запись portfolio.json в том же
хранилище, редактируемая через существующую админку. При первом старте релиза
добавляется под блокировкой и отмечается маркером: повторный старт не создаёт
дубль, не перезаписывает изменения и не восстанавливает удалённый кейс.

Три локальных SVG: широкий, вертикальный и длинный. Дополнительно поддержан
прямой переход `?gallery_demo=1` / `startapp=gallery_demo` к этой же записи.
Скрытый/удалённый кейс по ссылке не показывается: используется публичная выборка.
При откате просмотрщика оставить файлы img/gallery-demo, чтобы кейс не потерял фото.

Проверить: центрирование, миниатюры, свайпы/стрелки и границы списка,
pinch→pan без переключения, сброс масштаба при смене фото, возврат в кейс.

## Управление на компьютере

- Двойной щелчок или кнопка: увеличить / вписать.
- Ctrl + колёсико над фото: плавный масштаб 1–4× относительно курсора.
- Pinch на трекпаде поддерживается, если WebView передаёт Ctrl+wheel.
  Если система перехватывает жест, доступны кнопка и клавиатура.
- Обычное колёсико / прокрутка трекпада: стандартное перемещение увеличенного фото.
- Левая кнопка мыши + движение: перемещение; курсор grab/grabbing.
- Без Ctrl/Cmd: + / − — масштаб, 0 — вписать; стрелки перемещают увеличенное фото,
  а в исходном масштабе ← / → переключают кадры. Escape закрывает просмотр.
- Подсказки зависят от типа указателя, меняются при переходе между мышью и касанием.
