# Аудит кода: 11 ноября 2026

Проверены границы HTTP/Telegram-ввода, сохранение и адресация заявок,
блокировки хранилища, создание кейсов, импорт канала, вывод контента Mini App,
фоновые уведомления и существующие регрессионные тесты. Это проверка кода и
автоматических сценариев, а не замена приёмки в Telegram.

## Исправлено

- PR #38: Unicode в подписи Mini App приводил к исключению. Добавлены
  безопасное сравнение, отказ при повторных полях, обязательная дата с допуском
  часов 60 секунд и проверка числового ID. Webhook также отклоняет не-ASCII секрет.
- PR #39: совпадение предварительных номеров мастера создавало два кейса с одним
  ID; метаданные нового могли попасть в старый. Номер проверяется под блокировкой,
  мастер использует фактический ID сохранённого кейса. Старые данные сохранены.
- PR #40: адреса изображений в галереях и профиле не экранировались. Добавлены
  экранирование, допустимые протоколы ссылок, запасное фото профиля и lazy loading
  галерей разделов. Новых библиотек, фоновой анимации и сетевых запросов нет.
- Старый обработчик Telegram sendData не проверял форму брифа. Теперь HTTP и
  Telegram используют одну валидацию; чужой draft_id получает понятный отказ.
  Некорректный исходный JSON больше не записывается целиком в журнал.

## Проверки и ограничения

1006 Python-тестов, 23 JavaScript-теста; проверка синтаксиса JS и git diff --check.
Новые тесты используют временное хранилище и моки Telegram. Ошибки подписи,
коллизии кейсов и старого обработчика воспроизведены до исправления.

MANUAL TEST PENDING: реальная доставка ответа, загрузка фото/альбома,
публикация черновика, сохранение после перезапуска и холодный старт внутри Telegram.
Проверки отложены владельцем. Сообщения реальным заказчикам не отправлялись.

Ограничения архитектуры: уведомления владельцу имеют at-least-once доставку;
при неопределённом сетевом результате возможен повтор. Ответы клиентам используют
отдельную защиту от повторной отправки. JSON-документы Redis читаются целиком;
это потребует отдельного измерения при росте истории. Миграция данных и кеширование
авторизации без подтверждённой нагрузки в этот пакет не входят.
