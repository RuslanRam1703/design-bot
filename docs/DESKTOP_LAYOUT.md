# Адаптивная компоновка Mini App

Один интерфейс подстраивается под фактическую ширину окна. До 900 px остаются нижняя навигация и последовательная компоновка. От 900 px навигация располагается сверху, обычный кейс показывает изображения рядом с описанием, параметры расчёта — рядом с итогом. Контент ограничен 1200 px. От 1100 px сетка портфолио содержит четыре колонки. Кейсы с галереями внутри разделов сохраняют последовательную подачу.

В совместимых настольных клиентах Telegram (API 8+) есть добровольная кнопка «На весь экран». Отказ Telegram не блокирует приложение; отображается объяснение. Размер внешнего окна определяет Telegram. В обычном браузере достаточно расширить окно. Обработчики fullscreen подписываются один раз; CSS не пересоздаёт форму при изменении ширины.

MANUAL TEST PENDING: Telegram Desktop — вход/выход из полного экрана, изменение ширины, просмотр кейса и зум, заполнение заказа; телефон — нижняя навигация и галерея. Автоматически проверены отказ fullscreen, отсутствие автозапуска и повторных подписок, сохранение порядка разделов кейса. Локальный Chromium в текущей среде блокируется при запуске, поэтому визуальные проверки ширин 360/510/900/1280 px не подтверждены.
