# Telegram-бот + Mini App для дизайнера-фрилансера

Бот на Python (aiogram 3) с мини-приложением (портфолио, калькулятор стоимости,
приём заявок). Собрано по «Техзадание_для_Claude_Code.md» и данным из
«Калькулятор_стоимости_дизайна.xlsx» — цены и опции уже перенесены в
[data/pricing.json](data/pricing.json).

Инструкция ниже написана без предположения, что вы программист — просто
следуйте шагам по порядку. Там, где нужно, есть кнопка запуска команды.

> ⚠️ **Важно про Render free tier и `/admin`.** Бесплатный тариф Render
> использует эфемерную файловую систему — она сбрасывается при каждом
> передеплое и может сброситься при перезапуске после «засыпания». Админка
> (`/admin`: добавление/редактирование/удаление кейсов, FAQ, «Обо мне»)
> пишет изменения в файлы на диске (`data/*.json`, фото кейсов) — на
> бесплатном тарифе эти правки могут пропасть при следующем перезапуске
> сервиса. Это не баг в коде, а особенность инфраструктуры. Решение
> (persistent disk на платном тарифе, или вынос хранения во внешнюю БД) —
> отдельная задача, пока не сделана. До неё стоит либо не полагаться на
> `/admin`-правки как на постоянные, либо сразу использовать платный тариф
> с Persistent Disk.

## Что нужно сделать (коротко)

1. Установить Python на свой компьютер.
2. Проверить бота локально в браузере (без Telegram — просто чтобы увидеть, что всё работает).
3. Узнать свой `chat_id`, чтобы заявки клиентов приходили именно вам.
4. Разместить проект на бесплатном хостинге Render.com (получите постоянный HTTPS-адрес).
5. Указать этот адрес в BotFather (по желанию) и написать боту `/start`.

---

## 1. Установка Python

1. Зайдите на [python.org/downloads](https://www.python.org/downloads/) и скачайте установщик (версия 3.11 или новее).
2. Запустите установщик. **Обязательно поставьте галочку «Add python.exe to PATH»** внизу первого экрана — без неё команды ниже не заработают.
3. Нажмите «Install Now» и дождитесь окончания.
4. Откройте PowerShell (Пуск → напишите «PowerShell» → Enter) и проверьте:

```bash
python --version
```

Должна появиться строка вроде `Python 3.12.x`. Если пишет «команда не найдена» — переустановите Python и не забудьте галочку «Add to PATH».

---

## 2. Настройка проекта

1. Скопируйте всю папку `design-bot` туда, где вам удобно (например, `D:\design-bot`).
2. В PowerShell перейдите в эту папку и установите зависимости:

```bash
cd D:\design-bot
pip install -r requirements.txt
```

3. Скопируйте файл `.env.example` в `.env` (просто дублируйте файл и переименуйте копию) и откройте `.env` в блокноте. Заполните:

```
BOT_TOKEN=ваш_токен_от_BotFather
DESIGNER_CHAT_ID=
WEBAPP_URL=http://localhost:8080
PORT=8080
```

`DESIGNER_CHAT_ID` пока оставьте пустым — узнаете его на шаге 3.
`WEBAPP_URL=http://localhost:8080` подходит только для локальной проверки в
обычном браузере (шаг 2.1 ниже). Для реальной работы в Telegram потребуется
**HTTPS**-адрес — это будет адрес с Render.com, см. шаг 4.

### 2.1. Проверка в обычном браузере (без Telegram)

Это удобно, чтобы посмотреть, как выглядит и работает мини-приложение, ещё
до того, как вы всё выложите в интернет.

```bash
python -m bot.main
```

Если всё настроено верно, в консоли появится сообщение о том, что сервер
запущен, и бот в Telegram уже отвечает на `/start`. Откройте в браузере
**http://localhost:8080** — увидите портфолио и калькулятор. Заявка на
экране «Отправить» в браузере не уйдёт настоящему боту (это доступно только
внутри Telegram), но вы увидите, какие данные должны были уйти.

Остановить сервер — `Ctrl+C` в окне PowerShell.

---

## 3. Узнать свой chat_id (куда будут приходить заявки)

1. Пока бот запущен (шаг 2.1) или уже задеплоен (шаг 4), напишите ему в
   Telegram `/start`, затем `/id`.
2. Бот пришлёт число вида `123456789` — это ваш `chat_id`.
3. Впишите это число в `.env` (локально) и/или в переменные окружения на
   Render (шаг 4) в поле `DESIGNER_CHAT_ID`.

---

## 4. Деплой на Render.com (бесплатный HTTPS-хостинг)

Render подходит лучше всего для новичка: не нужно настраивать сервер
вручную, HTTPS выдаётся автоматически, есть бесплатный план.

### 4.1. Выложите код на GitHub (без командной строки)

1. Зарегистрируйтесь на [github.com](https://github.com), если ещё нет аккаунта.
2. Нажмите «New repository», назовите его, например, `design-bot`, оставьте
   приватным («Private») или публичным — на ваш выбор, нажмите «Create repository».
3. На странице репозитория нажмите «uploading an existing file» и
   перетащите туда все файлы и папки проекта (`bot/`, `webapp/`, `data/`,
   `requirements.txt`, `Procfile`, `render.yaml`, `.gitignore`,
   `README.md` и т.д.) — **кроме файла `.env`**, его загружать не нужно
   (он и так исключён через `.gitignore`, но проверьте, что не added вручную).
4. Нажмите «Commit changes».

### 4.2. Создайте сервис на Render

1. Зарегистрируйтесь на [render.com](https://render.com) (можно через GitHub-аккаунт).
2. «New +» → «Web Service».
3. Подключите репозиторий `design-bot`, который вы создали на GitHub.
4. Render сам подхватит настройки из `render.yaml` (Python, команда запуска).
   Если спросит вручную:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python -m bot.main`
5. Придумайте имя сервиса, например `my-design-bot` — тогда ваш адрес будет
   `https://my-design-bot.onrender.com` (запомните его, понадобится дальше).
6. В разделе **Environment** добавьте переменные:
   - `BOT_TOKEN` — токен бота
   - `DESIGNER_CHAT_ID` — ваш chat_id из шага 3
   - `WEBAPP_URL` — `https://my-design-bot.onrender.com` (без слэша на конце, именно тот адрес из пункта 5)
7. Нажмите «Create Web Service» и дождитесь деплоя (несколько минут).

> На бесплатном плане Render «засыпает» сервис после ~15 минут без
> обращений, и первое сообщение после сна может обрабатываться на 30–60
> секунд дольше обычного. Для «боевого» использования можно перейти на
> платный план прямо в настройках сервиса.

### 4.3. Проверка

Напишите боту в Telegram `/start` — должно появиться приветствие и меню из
четырёх кнопок. Нажмите «📁 Портфолио» или «💰 Рассчитать стоимость» —
должно открыться мини-приложение.

## 5. Что можно менять без программирования

Все тексты и цены вынесены в JSON-файлы в папке `data/` — их можно
редактировать прямо на GitHub (кнопка «карандаш» на странице файла) без
установки чего-либо на компьютер. После сохранения изменений на GitHub
Render автоматически передеплоит сервис.

- **`data/pricing.json`** — базовые цены, сроки и опции по всем 9 услугам,
  коэффициенты «срочно» / «сложно».
- **`data/faq.json`** — вопросы и ответы. Пункты с `"needs_review": true`
  — черновики (см. ТЗ, раздел 3, помечено `[уточнить]`) — замените
  `"answer"` на финальный текст и уберите `"needs_review"` или поставьте
  `false`.
- **`data/portfolio.json`** — кейсы портфолио. Сейчас там 8 примеров-заглушек
  (реальные кейсы ещё не собраны, см. ТЗ, раздел 5). Замените `title`,
  `task`, `solution`, `result`, `related_service` на настоящие данные, а
  картинки положите в `webapp/img/portfolio/` и укажите пути в полях
  `cover` / `images`.

Менять код (`bot/`, `webapp/js`, `webapp/css`) уже сложнее — для этого
пригодится помощь Claude Code.

## 6. Как устроен проект (для справки)

```
data/               исходные данные — правьте здесь
  pricing.json       услуги, опции, коэффициенты, формула вилки
  faq.json           15 вопросов из ТЗ
  portfolio.json     кейсы портфолио (сейчас — заглушки)

bot/                Python-бот (aiogram 3) + веб-сервер для Mini App
  main.py            точка входа: поднимает и бота, и сервер одновременно
  config.py          чтение .env
  calculator.py      серверный (авторитетный) пересчёт стоимости
  lead.py            форматирование заявки для сообщения дизайнеру
  keyboards.py       клавиатуры бота
  texts.py           тексты сообщений бота
  handlers/
    start.py          /start, /id, /cancel
    faq.py             раздел «Частые вопросы»
    webapp.py          приём данных из Mini App (заявка, файл ТЗ)

webapp/             Mini App: HTML/CSS/JS, без внешних зависимостей
  index.html
  css/style.css
  js/app.js           экраны: портфолио, кейс, калькулятор, бриф
  js/calculator.js     логика расчёта (зеркало bot/calculator.py)
  img/portfolio/       картинки кейсов (сейчас — SVG-заглушки)
```

### Важные технические решения (чтобы понимать логику, если будете расширять)

- Бот и веб-сервер Mini App работают в **одном процессе** (`python -m bot.main`) —
  для Render это один «Web Service», ничего дополнительно разворачивать не нужно.
- Бот использует **polling** (сам спрашивает Telegram о новых сообщениях),
  а не webhook — так проще для небольшого бота и не нужно настраивать
  входящие HTTPS-запросы к самому боту.
- Экран «Заявка / бриф» реализован **внутри Mini App** (не как отдельный
  чат-диалог), а бот-меню «✍️ Оставить заявку» открывает Mini App сразу на
  этом экране. Так же после «Хочу похожий проект» в кейсе и «Отправить
  заявку с этим расчётом» в калькуляторе — они переводят в бриф с уже
  подставленной услугой.
- Расчёт стоимости продублирован в двух местах с одинаковой формулой:
  `webapp/js/calculator.js` (для мгновенного отображения вилки цены прямо
  в интерфейсе) и `bot/calculator.py` (сервер пересчитывает то же самое
  ещё раз перед отправкой заявки дизайнеру — чтобы в уведомлении всегда
  были верные цифры, даже если кто-то вмешается в данные на телефоне).
- Пункт «Есть подробное ТЗ? → Да» устроен так: Mini App не может напрямую
  прикреплять файлы, поэтому после отправки заявки бот просит прислать файл
  обычным сообщением в чат и пересылает его дизайнеру.
